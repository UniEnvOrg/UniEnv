    Bases: SpaceStorage[HDF5BatchType, NumpyArrayType, NumpyDeviceType, NumpyDtypeType, NumpyRNGType]

    Stores samples of a (nested) DictSpace / BoxSpace / BinarySpace / TextSpace in one HDF5 file, one dataset per leaf, numpy backend only.

    Dataset layout, chosen by create() from chunks / compression (a mapping sets them per key, "*" for the remaining keys):

    • Fixed capacity, no compression, chunks=None (the default): contiguous datasets, the fastest layout for per-step appends and random reads.
    • chunks=None or chunks=True with compression, or an unbounded storage: chunks of whole rows of about CHUNK_TARGET_BYTES (64 KiB), e.g. one 128x128x3 uint8 image or ~2300 7-float rows per chunk, so a row access touches (and decompresses) a single chunk. Compressed files come out somewhat larger than with h5py's sub-row chunk guess, which made every image read decompress dozens of chunks.
    • An explicit tuple is used as given, padded with the row shape: chunks=(1,) stores every step in its own chunk (the per-step layout: cheapest single-row writes and reads with compression, worst ratio).

    Compression ("gzip", "lzf") trades write and random-read speed for size. For camera images prefer VideoStorage (or ImageStorage with JPEG / PNG) over gzip-compressed HDF5; keep low-dim keys uncompressed.

    open_segment_writer() -> SegmentWriter

    A writer that builds one segment of this storage off to the side; see SegmentWriter. Unlike mark_segment_start() / append(), any number of writers can be open at a time. The default keeps the samples in memory until the commit; storages override it to stream instead.

    read_sorted_unique_rows ¶

    read_sorted_unique_rows(dataset: Dataset, index: ndarray) -> ndarray

    dataset[index] for a sorted, duplicate-free integer array, without h5py point / fancy selections (which build one hyperslab per element and are 10-100x slower than plain slices). Dense or small spans are read as one bounding slice; otherwise every run of consecutive rows is one slice read.

    write_rows ¶

    write_rows(
    dataset: Dataset, start: int, value: Any, num_rows: Optional[int] = None
) -> bool

    dataset[start:start + num_rows] = value through the low-level h5py API when value is a plain array of exactly num_rows whole rows: skips h5py's selection / broadcasting machinery (~30us of Python per call, 3-4x the cost of the write itself). Returns False (writing nothing) when the fast path does not apply.
